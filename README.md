## 🌟 Website Ke Bare Mein

**DevOps Learning Hub** ek beginner-friendly static website hai jo DevOps seekhne walon ke liye banayi gayi hai. Is website mein:

- 🔐 **Student Login Page** — Username & Password ke sath demo frontend login
- 📚 **DevOps Courses Section** — Linux, Git & GitHub, AWS Cloud, Bash Scripting, Docker, CI/CD
- 🗺️ **Beginner DevOps Roadmap** — Step-by-step guide (IT Basics → Linux → Git → Bash → AWS → Docker → CI/CD → Monitoring & Projects)
- 🛠️ **Popular DevOps Tools** — Linux, Git, GitHub, Bash, AWS, Docker, Jenkins, GitHub Actions, Nginx, Terraform, Kubernetes
- 🎨 Clean, responsive aur beginner-friendly design
